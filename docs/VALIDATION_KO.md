GT 재계산은 Food/Power 각각 1조건·1구성원과 Kuramoto 1개 초기위상의 전체 21개 continuation 조건으로 확인했습니다. 전체 GT 앙상블을 이번 패키징 과정에서 새로 계산한 것은 아닙니다. Kuramoto는 저장 기록의 정확한 K 배열을 재사용합니다.

BO 전체 재실행, 새로운 재귀 행렬 생성, 모든 훈련 ODE 시퀀스 재생성은 이 패키지의 검증 범위가 아닙니다. 상세 숫자와 실행 범위는 `provenance/packaging_validation.json`에 있습니다.

## 기본 모델 선택 수정

테스트는 새 훈련 파일이 있어도 제출 모델을 기본으로 사용합니다. 재학습 readout은 `--readout`으로 명시한 경우에만 사용합니다. 작은 가중치 오차를 긴 자율 궤적이나 판정의 동일성으로 해석하면 안 됩니다.

Power의 두 모델을 각각 35조건 × 50개, 2,000샘플로 새로 평가했습니다.

| 항목 | 제출 모델: 기본 실행 | 재학습 readout: 명시적 선택 |
|---|---|---|
| 조건 18 생존율 | 0.12 | 0.26 |
| SCDT 50% crossing σ | 0.03273458497180605 | 0.03274668221532637 |
| 환산 Q₁ | 2.989795250 | 2.9897963636363634 |
| MAE: 백분율 포인트 | 17.7142857143 | 17.3142857143 |

나머지 34조건의 생존율은 같았습니다. 기본 실행의 전체 1,750개 궤적은 저장된 제출 궤적과 동일했습니다. GT crossing σ=0.033059222141686974보다 두 SCDT crossing이 모두 작아 순서는 유지됩니다. 제출 그림·수치·모델은 변경하지 않았습니다.

훈련 결과 파일 자동 선택 방지 회귀 테스트를 포함한 8개 테스트가 통과했습니다. 상세 비교는 `provenance/default_readout_validation.json`에 있으며, 새 실행마다 `model_selection.json`에 실제 선택한 가중치의 파일명과 해시를 남깁니다. 다른 수치 라이브러리·하드웨어에서의 동일성까지 보장하는 검증은 아닙니다.
